# Echoes of You

I am participating in a 6-hour frontend hackathon called WebRush.

The challenge is:

"Your Life, In Receipts"

The goal is to transform a collection of fictional digital-life receipts into a meaningful, interactive story.

The dataset contains different types of digital-life activity including:

- Music

- Purchases

- Transactions

- Places

- Events

- Other digital-life moments

The experience must go beyond simply displaying a chronological timeline.

It must provide:

1. A way to explore receipts

2. Meaningful search and filtering

3. Discovery of relationships and patterns

4. Interactive storytelling

5. A clear visual representation of the digital journey

6. Responsive design

7. Good accessibility

8. Good performance

9. Clean, maintainable frontend code

IMPORTANT:

This is a FRONTEND-ONLY hackathon.

Do not create a backend.

Do not create authentication.

Do not create a database server.

All data processing must happen in the frontend or through static/preprocessed data.

TECH STACK:

- React

- Vite

- TypeScript if useful

- Modern CSS/Tailwind if useful

- Use lightweight visualization libraries only when they add real value.

PROJECT CONCEPT:

The product should feel like an interactive digital museum rather than a conventional dashboard.

Working title:

LIFE//RECEIPTS

Tagline:

"Every ordinary moment leaves a trace."

CORE VISUAL IDEA:

The user's digital life is represented as a constellation of moments.

Each receipt is a point/node.

Different receipt categories have different visual identities.

Related or temporally close moments can form clusters.

Users should be able to explore these moments and discover connections.

The visual language should combine:

- digital museum

- editorial storytelling

- constellation/data visualization

- subtle scrapbook/receipt elements

- cinematic transitions

- modern typography

- restrained color palette

- sophisticated motion

DO NOT make this look like:

- a generic SaaS dashboard

- an admin panel

- a generic AI dashboard

- a Bootstrap template

- a page full of identical cards

- a generic purple-gradient AI website

Create the initial application architecture and a polished landing page that establishes this visual identity.

Do not try to implement every feature yet.

First focus on:

- application structure

- navigation

- visual identity

- landing/intro experience

- responsive foundation

- reusable component architecture

Use mock data temporarily if the actual dataset is not yet connected.

Make the experience feel premium, experimental and memorable.
